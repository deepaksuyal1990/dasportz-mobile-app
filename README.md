# DA SPORTZ Mobile App

Official mobile app for [DA SPORTZ](https://dasportz.com/) — 100% genuine sports equipment and official gear with express nationwide delivery.

Built with **Expo** and **React Native** (TypeScript).

## Features

- **Home** — Brand overview, key highlights, and product collections
- **Products** — Cricket bats & gear, trophies & awards, Freebowler bowling machines
- **Services** — Badminton stringing, cricket bat knocking, gloves repair, bat repair
- **Contact** — Call, email, WhatsApp, maps, and store details
- **WhatsApp enquiries** — One-tap product and service booking

## Getting Started

### Prerequisites

- Node.js 18+
- [Expo Go](https://expo.dev/go) on your phone, or Xcode / Android Studio for simulators

### Install & Run

```bash
npm install
npm start
```

Then:

- Press `i` for iOS simulator
- Press `a` for Android emulator
- Scan the QR code with Expo Go on your device

### Other Commands

```bash
npm run ios       # Open on iOS
npm run android   # Open on Android
npm run web       # Run in browser
```

## Project Structure

```
src/
├── components/     # Reusable UI components
├── constants/      # Theme (colors, spacing, typography)
├── data/           # Business content from dasportz.com
├── navigation/     # Tab + stack navigation
├── screens/        # App screens
└── utils/          # Phone, email, WhatsApp, maps helpers
```
